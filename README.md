# Animal Intrusion Detection and Repellent System Using AI, Computer Vision, and IoT

## Project Overview

Agriculture plays a vital role in food production and economic development. However, crop damage caused by animals such as cattle, dogs, monkeys, and wild animals results in significant losses for farmers. Traditional monitoring methods require continuous human supervision and are often ineffective during nighttime and adverse weather conditions.

This project presents an intelligent Animal Intrusion Detection and Repellent System that combines Artificial Intelligence (AI), Computer Vision, and Internet of Things (IoT) technologies to automatically detect animal intrusion and provide timely alerts. The system uses an ESP32-CAM module for image capture and real-time monitoring. Captured images are analyzed using a trained object detection model to identify animals entering the protected area.

When an animal is detected, the system generates alerts and can activate repellent mechanisms to help prevent crop damage. This approach reduces manual effort, improves field security, and supports smart agriculture practices.

## System Workflow

1. ESP32-CAM captures images from the monitoring area.
2. Images are transmitted for processing.
3. AI model analyzes the images and identifies animals.
4. Detection results are generated in real time.
5. Alert or repellent actions are triggered when intrusion is detected.
6. Farmers receive notifications and can take preventive measures.
